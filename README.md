# Anish Chand Gupta — Portfolio

Premium freelance portfolio focused equally on Web Development and AI / Automation.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Customize

- Main page/content: `app/page.tsx`
- Visual system/responsive styles: `app/globals.css`
- SEO metadata: `app/layout.tsx`

The portfolio intentionally uses a curated project selection rather than implying a large public project archive.
